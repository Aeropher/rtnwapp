You start with a set of tags: 💼 Work, 🏠 Home, 🧹 Chore, 💪 Health, 🛒 Errands, 💰 Money, 👪 Family and 🎉 Fun.

## Add a tag to a task

**In the editor:** tap one of the suggested tag chips, or tap **Add tag** to open **Select Tags** and choose from all of them.

**While adding a task:** type `#` and the tag's name, for example `#work`. Emoji are ignored when matching, so `#movie` finds "🎬 Movie".

## Create a tag

1. In the editor, tap **Add tag**.
2. In **Select Tags**, tap **New tag**.
3. Give it a **Tag Name**, an optional description and a **Color**. The **Preview** shows how it'll look.
4. Tap **Create**.

Each tag needs a name you haven't already used.

Typing `#something` for a tag you don't have yet won't create it. It's quietly left out.

## Take a tag off a task

In the editor, tap the **×** on the tag's chip.

## Repeating badge

Repeating tasks show a 🔄 Repeating badge. It isn't a tag: you can't add or remove it, and it goes away when the task stops repeating.
